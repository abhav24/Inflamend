# UX Simplification Report

## Product Model

Target top-level structure:

1. Today
2. Log
3. Insights
4. Care
5. Profile

Current structure:

1. Home
2. Log
3. Insights
4. Ask
5. You

## Recommended Changes

- Rename Home to Today.
- Rename Ask to Care and include AI, red flags, education, questions for doctor, and flare action plan.
- Keep Log progressive rather than seven dense top tabs where possible.
- Replace overconfident trigger copy with cautious possible-pattern copy.
- Make one clear Check In button on Today.
- Add Low-Spoon Mode for flare days.
- Move export/delete/privacy controls into Profile with explicit setup states.

## Current Status

Visual style is polished but the product is still demo-heavy. Simplification should happen alongside persistence and safety work.
